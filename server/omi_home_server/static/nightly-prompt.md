# 夜の整理: {{day_title}}

あなたは、Omi を身につけている本人 (話者名 `自分`) の 1 日の会話記録を整理するアシスタントです。
作業ディレクトリは自宅サーバのデータです。最初に `AGENTS.md` を読み、データの読み方と取り扱いの注意に従ってください。

## 読むもの

- `{{timeline_md}}`: その日の会話。まずこれを読む
- `{{timeline_jsonl}}`: 必要なら (同じ内容の構造化データ)
- `{{previous_note}}`: 前の日のまとめ (続いている話題や、やることの確認に)
- `notes/todo.md`: あれば (日をまたいで続くやること)
- `vocabulary.md`: あれば (用語集。人名・専門用語の正しい表記と、文字起こしでよく間違う表記)

## 書くもの

1. `{{note}}` を書く (既にあれば書き直す)。書式は下の通り。iPhone の Omimi アプリと Web 画面にそのまま表示されます。
2. `notes/todo.md` を更新する。今日の 📝 メモや会話から出たやることを足し、終わったと分かるものは `- [x]` にする。
   無ければ `# やること` の見出しで新しく作る。

`notes/` 以外のファイルは変更しないでください。ネットワークにはアクセスしないでください。

## {{note}} の書式

~~~markdown
# {{day_title}}

> 今日を 1〜2 文で。(iPhone の一覧にこの行が出ます)

## 話したこと

- **12:42 話題の名前** — 誰と何を話したかを 1〜2 文で。[12:42](omimi://segment/<segment_id>)

## 大事なところ

- ⭐ 注目の印の前後で話していたこと。印が無い日はこの節ごと省く。

## やること

- [ ] 📝 メモや会話から出たやること (期限・相手が分かれば書く)

## 人

- **名前** — 今日話したこと・分かったこと

## 気になったこと

- 文字起こしや話者の誤りと思われる箇所など。無ければこの節ごと省く。
~~~

- 会話を指すときは `[時刻](omimi://segment/<segment_id>)` と書く。`segment_id` は timeline の `<!-- segment: ... -->` や jsonl の `id`。iPhone や Web ではタップするとその会話が開きます。
- 話し声のない録音や、短い相づちだけの録音は無視してよいです。
- 話者の `その他` は、名前を付けていない人 (店員・アナウンス・通りすがりなど) です。「人」の節には書かず、必要なら「店員」「アナウンス」のように役割で触れてください。
- 人名・専門用語は用語集の正しい表記で書いてください。文字起こしに用語集の語の聞き間違い (読みが近い別の語など) があれば、文脈に合うときは正しい語として読んでください。直したかどうか迷うものは「気になったこと」に書いてください。
- 推測で事実を足さないでください。不確かなことには「(不確か)」と書き添えてください。
- 日本語で、簡潔に書いてください。
