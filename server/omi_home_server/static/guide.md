# 毎日の流れ

昼は Omi で録音して iPhone にためておき、夜に自宅の Mac (自宅サーバ) で整理します。iPhone と Mac は Wi-Fi か Tailscale でつながるので、ケーブルは要りません。

1. **送る**: iPhone が録音と文字起こしを Mac に送ります。iPhone も充電中に自分で話者を聞き分けます (下の「iPhone だけで使う」)。
2. **処理する**: Mac が話者を聞き分け、文字起こしを整えます。Mac の結果が届いた録音は、そちらを使います。
3. **整理する**: AI がその日のまとめとやることを `data/notes/` に書きます。この画面の「まとめ」→「AI で整理」から、ChatGPT のプランで動かせます。
4. **届ける**: Omimi を開くと、まとめが「まとめ」タブと「記録」に届きます。

いまどこまで進んでいるかは、この画面の上の「今夜の状況」で確かめられます。

## 夜にすること

### 1. iPhone を家の Wi-Fi につなぐ

- 帰宅したら Omimi を一度開きます。「まとめ」タブの **送る** に ✓ が付けば、その日の録音はすべて Mac に届いています。
- 充電中は、アプリを開いていなくても iOS が空いた時間に送ります。
- 「Wi-Fi のときだけ送る」がオンだと、モバイル通信では送りません。

### 2. Mac の処理が終わるのを待つ

- 「今夜の状況」の **処理する** が ✓ になれば終わりです。1 日分で数分から十数分かかります。
- 待たずに 3 に進んでも構いません。整理は処理が終わるのを最大 60 分待ってから始めます。

### 3. AI に整理させる

**iPhone で**: Omimi の「まとめ」タブの「AI で整理」で、接続から整理まで iPhone だけでできます。「ChatGPT に頼むところ」を選べます。

- **この iPhone から**: iPhone が ChatGPT に直接頼みます。接続の情報は iPhone のキーチェーンにだけ置きます。自宅サーバにつながっていれば、サーバが作った記録 (話者・Whisper の文字起こし込み) を使い、つながらなければ iPhone の記録で書きます。書いたまとめは自宅サーバにも送ります。
- **自宅サーバから**: Mac が ChatGPT に頼みます (下の「ブラウザで」と同じ接続)。

**ブラウザで**: この画面の「まとめ」を開き、左上の「AI で整理」で操作します。

1. はじめてのときは「ChatGPT で続ける」を押し、開いた ChatGPT の画面で許可します (ChatGPT Plus または Pro が必要です)。
   - この Mac のブラウザで開いていれば、許可するとそのままつながります。
   - iPhone など、ほかの端末のブラウザで開いている場合は、許可のあとに「接続できません」のページが出ます。そのページのアドレスをコピーして、「AI で整理」の欄に貼り付けてください。
2. 整理する日とモデルを選んで「AI で整理する」を押します。1〜2 分でまとめが書かれ、iPhone にも届きます。
3. 使った量は「使用量を管理」(ChatGPT の設定) で確かめられます。

ChatGPT とのやりとりは、この Mac の自宅サーバが行います。接続の情報は Mac の中 (`data/chatgpt/`、所有者だけ読める) にだけ保存し、ブラウザには渡しません。

**ターミナルで**: Mac のターミナルで次を実行します。

```
cd ~/Documents/github/omi-original-app/server
./nightly-mac.sh
```

- 午前 5 時より前に実行すると、前の日を整理します。日付を選ぶときは `./nightly-mac.sh --day 2026-10-10` です。
- AI への指示は `data/prompts/nightly.md` です。書き換えると次の整理から反映されます。
- まとめは `data/notes/<日付>.md` に、日をまたいで続くやることは `data/notes/todo.md` に書かれます。
- AI を動かさずに指示だけ作るときは `./nightly-mac.sh --agent none` です。指示は `data/runs/prompt-<日付>.md` にできるので、Codex を自分で開いて渡せます。

### 4. iPhone で読む

- Omimi を開くか、「まとめ」タブを下に引っ張ると届きます。
- まとめの中の時刻 (例: 12:42) をタップすると、その会話が開きます。
- その日のまとめは「記録」の日付の下にも出ます。

## 毎晩自動で整理する

Mac にログインしている間、決まった時刻に 3 を自動で実行できます。

```
./nightly-mac.sh schedule 23:30
```

ブラウザで ChatGPT とつないだあとなら、Codex の代わりに、そのつながりで整理させることもできます。

```
OMI_AGENT_COMMAND=chatgpt ./nightly-mac.sh schedule 23:30
```

- やめるときは `./nightly-mac.sh unschedule` です。
- 実行の記録は `data/runs/nightly.log` に、結果はこの画面の「蓄積」の **最後の整理** に出ます。
- Mac がスリープしていた時刻の分は、起きたときに実行されます。

## 用語集 (人名・専門用語)

文字起こしでよく間違う語を、Web の「用語」か iPhone の「設定 → 用語集」で登録します。

- **正しい表記・読み・よく間違う表記・説明** を登録します。
- iPhone と自宅サーバの文字起こしで、ヒントとして使います (認識されやすくなります)。
- 「よく間違う表記」(2 文字以上) は、表示と AI 向けの書き出しで正しい表記に直します。元の文字起こしは残しています。
- AI がまとめるときは用語集を添付し、聞き間違い (読みが近い別の語など) を直して書かせます。
- 新しい録音から効きます。表示の補正は過去の録音にもすぐ反映されます。

## iPhone だけで使う (話者の聞き分け)

- iPhone も、自宅サーバと同じ AI モデル (話者の区切りと声の特徴) で話者を聞き分けます。音声は iPhone の外に出ません。設定の「話者の聞き分け」でオン・オフできます。
- 充電中とアプリを開いているときに、新しい録音から順に進みます。自宅サーバの結果が届いた録音は、サーバの結果を使います。
- 名前は、自宅サーバが学習した声 (`GET /api/v1/speakers/voices`) で当てます。自宅サーバを設定していなければ、iPhone で直した話者から iPhone が声を学習します。
- 名前のない声も、会話の中では人ごとに分けて表示します (どれも「その他」)。


- **名前を付けるのは大事な人だけ**: 自分や会社の人など、大事な人にだけ名前を付けます。名前のない声 (店員・駅や電車のアナウンス・通りすがりなど) は、すべて「その他」としてグレーでまとめて表示します。
- **よく聞く声**: 名前のない声のうち、2 日以上聞いた声や合計 1 分以上の声は、「話者」に「よく聞く声 (名前を付ける候補)」として出ます。発話を聞いて、大事な人なら名前を付けます。アナウンスなどなら「その他にする」を押すと、候補に出なくなります。
- **声ごと名前を付ける**: 会話の中の「その他」をタップして「すべての録音」(Web では「この声のすべての録音」) を選んで名前を付けると、ほかの録音のその声にもまとめて名前が付きます。
- **発話の話者を直す**: 会話の中の話者名 (iPhone では名前の横の ⌄、Web では名前) をタップし、正しい人を選びます。「この発話だけ」か「この録音のその人すべて」を選べます。新しい名前も入力できます。
  - iPhone では直した内容がすぐ画面に反映され、自宅サーバにつながったときに送られます。
- **声を学習する**: 名前を付けた人の発話から、自宅サーバがその人の声を学習します。人が直した・確かめた発話は重く扱います。直してから 10 秒ほどで学習し直し、過去の録音の話者も付け直します (人が直したところは変えません)。次からの録音は、学習した声で先に照合します。
- **その人らしくない発話を確かめる**: Web の「話者」(iPhone は「設定 → 話者と声の学習」) で人を選ぶと、その人の発話のうち声が似ていないものが「確認したい発話」に並びます。▶ で聞いて、「この人で合っている」「別の人に直す」「不明」を選びます。
- 同じ人が 2 人に分かれていたら、Web の「話者」で「同じ人としてまとめる」を使います。

## 文字起こしの聞き比べ

この画面の「聞き比べ」で、iPhone (Apple の音声認識) と自宅サーバ (Whisper) の文字起こしを、どちらのものか伏せて A / B に並べます。

- ▶ (スペース) で音声を聞き、正しく書けている方を選びます (1〜4 のキーでも選べます)。
- 20 件ほど選ぶと、どちらが良いかが出ます。「これから 〇〇 を使う」を押すと、まとめと書き出し (`timeline/`) に使う文字起こしが切り替わります。
- 両方の文字起こしがある録音だけが対象です。iPhone の「設定 → 自宅サーバ」で「サーバでも文字起こしする」をオンにすると増えます。


- 「AI で整理」(ChatGPT) も Codex も、OpenAI のサーバで動くモデルを使います。**整理する日の文字起こし (AI が読んだファイル) が OpenAI に送られます。** 送りたくない日は 3 を実行しないでください。
- iPhone の「この iPhone から」で整理したときは、iPhone から OpenAI に送られます。それ以外のとき、iPhone は OpenAI と通信しません。
- 「AI で整理」では、自宅サーバが `AGENTS.md`・その日の会話・前の日のまとめ・やることだけを添付して送ります。AI がほかのファイルを開くことはありません。
- AI は、データのフォルダの中だけを書き換えられ、コマンドからはネットワークに出られない設定 (`--sandbox workspace-write`) で動かしています。
- 外に出さずに整理したいときは、Mac や DGX Spark で動くローカルのモデルに切り替えられます (Ollama とモデルの準備が必要です)。

```
OMI_AGENT_COMMAND="codex exec --oss --local-provider ollama --skip-git-repo-check --sandbox workspace-write --cd {data_dir} -" ./nightly-mac.sh
```

## データの置き場所

| 場所 | 中身 |
|---|---|
| `data/audio/` | 音声 (Ogg Opus) と、録音ごとの詳細 |
| `data/timeline/` | 日ごとの会話。AI はまずこれを読みます |
| `data/notes/` | AI のまとめ。iPhone に届きます |
| `data/prompts/nightly.md` | AI への指示 |
| `data/runs/` | 整理の記録 |
| `data/omi.sqlite3` | すべての記録のデータベース |
| `data/AGENTS.md` | AI 向けの、データの読み方 |

## うまくいかないとき

- **送る が ✓ にならない**: iPhone の「設定 → 自宅サーバ」で「接続を確かめる」を押します。Mac でサーバ (`./run-mac.sh`) が動いているかも確かめてください。
- **処理する が終わらない**: サーバを動かしているターミナルにエラーが出ていないか確かめてください。
- **まとめが書かれない**: 「蓄積」の **最後の整理** に理由が出ます。ターミナルで `./nightly-mac.sh` を実行すると、AI の出力をそのまま見られます。
- **iPhone にまとめが来ない**: 「まとめ」タブを下に引っ張って更新します。iPhone がまとめを受け取ると、「今夜の状況」の **届ける** が ✓ になります。
