自宅サーバの記録を開く

API トークンを入力してください。トークンはサーバで omi-server token を実行すると表示されます。入力したトークンはこのブラウザにだけ保存します。

Omimi

記録 まとめ 話者 用語 聞き比べ 蓄積 使い方

      用語

      人名や専門用語など、文字起こしでよく間違う語を登録します。iPhone と自宅サーバの文字起こしでヒントとして使い、「よく間違う表記」は表示と書き出しで正しい表記に直します。AI がまとめるときにも参考にします。

      聞き比べ

      iPhone (Apple の音声認識) と自宅サーバ (Whisper) の文字起こしを、どちらのものか伏せて A と B に並べます。音声を聞いて、正しく書けている方を選んでください。20 件ほど選ぶと、どちらを使う方が良いかが分かります。

      蓄積

      ChatGPT のプランを使っています

      AI で整理するときは、あなたの ChatGPT のプランが使われます。使用量は ChatGPT の設定で確かめたり、変えたりできます。整理する日の文字起こしは OpenAI に送られます。
